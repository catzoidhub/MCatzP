# DBCatz tools

Generated by DBCatz's `scripts/mcatzp-tools.ts`: do not edit by hand. A client sees each one as `dbcatz_<name>`, and only those that Settings → MCatzP allows. Every tool runs on macOS and Windows.

## Read: runs at once, inside what is shared (16)

| Tool | What it does | Inputs |
|---|---|---|
| `list_connections` | The connections shared with you: id, name, engine, where it is, its mode (normal, production, readonly), whether it is running and connected, and its source: saved by the user, or a service from DevCatz or DoCatz. No passwords. | None. |
| `server_info` | The server's version. Connects if DBCatz is not connected yet. | `connection`: The connection's id or name (see list_connections). |
| `list_databases` | The databases of a connection, with the ones the user starred and used lately. | `connection`: The connection's id or name (see list_connections). |
| `list_tables` | Tables and views of a database (MongoDB: collections; Elasticsearch: indexes), with estimated rows and size when the engine reports them. | `describe_table` | Columns with their types, indexes, foreign keys, the primary key and the CREATE statement. | `connection`: The connection's id or name (see list_connections).<br>`database`: The database (see list_databases). Redis / Valkey: db0, db1 …<br>`table`: The table or view. MongoDB: a collection. Elasticsearch: an index. |
| `list_column_types` | The column types this server offers. | `connection`: The connection's id or name (see list_connections). |
| `list_charsets` | The character sets and collations this server offers. | `connection`: The connection's id or name (see list_connections). |
| `list_saved_queries` | The queries the user saved for this database, with their text (secrets masked). | `connection`: The connection's id or name (see list_connections).<br>`database`: The database (see list_databases). Redis / Valkey: db0, db1 … |
| `check_alter` | What alter_table would risk, without changing anything: data that would not fit, a dropped column, what points at it. `level` is none, warn, danger (the user types a name) or block (refused). | `connection`: The connection's id or name (see list_connections).<br>`database`: The database (see list_databases). Redis / Valkey: db0, db1 …<br>`table`: The table or view. MongoDB: a collection. Elasticsearch: an index.<br>`ops`: What to change, in order. |
| `list_jobs` | Exports, imports and backups on the shared connections: how far each is, and how it ended. Check here after starting one, and tell the user. | None. |
| `list_query_log` | What ran on this connection since DBCatz opened, the newest first: the Logs tab. Statements, how long they took, rows changed and errors, with secrets masked. | `connection`: The connection's id or name (see list_connections).<br>`limit` (optional): 100 when left out. |
| `list_query_history` | Queries the user ran on this database since DBCatz opened, the newest first: the History list of the Query tab. Secrets masked. | `connection`: The connection's id or name (see list_connections).<br>`database`: The database (see list_databases). Redis / Valkey: db0, db1 … |
| `read_rows` | Rows of a table, a page at a time. Values under secret-looking columns come back as ••• and `masked` names those columns. Redis / Valkey: db0, db1 …<br>`table`: The table or view. MongoDB: a collection. Elasticsearch: an index.<br>`limit` (optional): Rows in this page; 50 when left out.<br>`offset` (optional): Rows to skip.<br>`order_by` (optional): A column to sort by.<br>`descending` (optional) |
| `run_read_query` | Runs a query that only reads: SELECT, SHOW, EXPLAIN, DESCRIBE (SQL), find / aggregate without $out (MongoDB), GET and _search (Elasticsearch), GET / HGETALL and the like (Redis, one command per line). Anything else is refused and names the statement. Results are cut at max_rows; values under secret-looking columns come back as ••• . | `connection`: The connection's id or name (see list_connections).<br>`database`: The database (see list_databases). Redis / Valkey: db0, db1 …<br>`query`<br>`max_rows` (optional): Rows per statement; 100 when left out.<br>`timeout_seconds` (optional): Gives up after this long; 30 when left out. |
| `list_keys` | Redis / Valkey: keys matching a glob, with type, TTL in seconds (-1 = no expiry) and size. | `connection`: The connection's id or name (see list_connections).<br>`database`: The database (see list_databases). Redis / Valkey: db0, db1 …<br>`pattern` (optional): A glob; * when left out.<br>`limit` (optional): 200 when left out. |
| `get_key` | Redis / Valkey: a key's value (a large one is cut: `shown` of `size`). A secret-looking key or hash field comes back as ••• . | `connection`: The connection's id or name (see list_connections).<br>`database`: The database (see list_databases). Redis / Valkey: db0, db1 …<br>`key`: The key. |

## Destructive: you type a name in DBCatz, every time (7)

| Tool | What it does | Inputs |
|---|---|---|
| `delete_rows` | Deletes rows, each found by its whole primary key. | `drop_database` | Removes a database and everything in it. The user types a name in DBCatz to allow it, every time. | `connection`: The connection's id or name (see list_connections).<br>`name`: The database. |
| `drop_tables` | Removes tables with their rows. Tables other tables point at are reported as failed. The user types a name in DBCatz to allow it, every time. | `connection`: The connection's id or name (see list_connections).<br>`database`: The database (see list_databases). Redis / Valkey: db0, db1 …<br>`tables` |
| `truncate_tables` | Removes every row of the tables; the tables stay. Tables other tables point at are reported as failed. The user types a name in DBCatz to allow it, every time. | `connection`: The connection's id or name (see list_connections).<br>`database`: The database (see list_databases). Redis / Valkey: db0, db1 …<br>`tables` |
| `delete_keys` | Redis / Valkey: removes keys and their values. The user types a name in DBCatz to allow it, every time. | `connection`: The connection's id or name (see list_connections).<br>`database`: The database (see list_databases). Redis / Valkey: db0, db1 …<br>`keys` |
| `flush_keys` | Redis / Valkey: removes every key in one database. The user types a name in DBCatz to allow it, every time. | `connection`: The connection's id or name (see list_connections).<br>`database`: The database (see list_databases). Redis / Valkey: db0, db1 … |
| `delete_connection` | Removes a saved connection and the password DBCatz keeps for it, which cannot be read back. Nothing on the server changes. Services from DevCatz and DoCatz are removed there. The user types a name in DBCatz to allow it, every time. | `connection`: The connection's id or name (see list_connections). |
